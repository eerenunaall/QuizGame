# ADR-0002: Monorepo, language and tooling

Status: Accepted · Date: 2026-10-06

## Context
GDD §4 prescribes pnpm + Turborepo + TypeScript and "Prisma or an equivalent mature ORM". Registry
check on 2026-10-06 showed: Prisma `latest` is a release candidate (8.0.0-rc), TypeScript 7.0.2 is
outside typescript-eslint's supported peer range (`<6.1.0`), Playwright 1.63 expects a newer
Chromium than the sandbox ships (revision 1194 → Playwright 1.56).

## Decision
| Concern | Choice | Why |
|---|---|---|
| Workspace | pnpm 10 + Turborepo 2 | GDD |
| Language | TypeScript 6.0.x, `strict`, `noUncheckedIndexedAccess`, ESM only | newest version lint tooling supports |
| Runtime | Node 22 LTS (`.nvmrc`) | sandbox + CI |
| Internal packages | consumed as TypeScript source via `exports` | no build step in dev; servers are bundled with tsup for production |
| Validation | zod 4 | one schema → types, runtime validation, JSON Schema for docs |
| HTTP | Fastify 5 + pino | schema hooks, structured logs, `inject()` for tests |
| WebSocket | `ws` (upgrade handled on the Fastify server) | GDD §4.3, no framework magic |
| DB access | `pg` + Kysely + hand-written SQL migrations in `database/migrations` | **No Prisma**: RC release, native engine downloads blocked/unverifiable in the sandbox, SQL migrations give full control over constraints (partial unique indexes, CHECKs, triggers) that idempotency and privacy rules depend on. Types generated by `kysely-codegen` and drift-checked in CI. |
| Tests | Vitest 5, fast-check 4 (property tests), Playwright 1.56 (E2E) | |
| Lint/format | ESLint 10 flat config + typescript-eslint (type-aware: `no-floating-promises`) + Prettier | |
| IDs | `crypto.randomUUID()` (v4) for internal ids; 256-bit random for secrets | GDD §18 |
| Time | all game logic takes `now` as an argument; `Date.now()` only at I/O edges | determinism |
| Syntax subset | `erasableSyntaxOnly` for every package that ships to clients (shared, protocol, game-engine, validation, i18n, controller-client, UI); server-only code (`apps/realtime`, `packages/db`, `tests`) may use constructor parameter properties | runs under Babel (React Native) and Node type stripping where it matters |

## Consequences
- Migrations are plain SQL, forward-only, checksummed, applied under an advisory lock.
- Upgrading TypeScript to 7 is a tracked follow-up once typescript-eslint supports it.

## Verification
CI runs `pnpm check` (lint, typecheck, unit), integration (Postgres service) and E2E.
